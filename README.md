# 🌸 ICFlor

Una **aplicación web moderna** construida con mejores prácticas de desarrollo JavaScript, configurada con un pipeline de CI/CD completo y pruebas automatizadas.

## 📋 Descripción del Proyecto

ICFlor es una aplicación web que demuestra la implementación de un **flujo de trabajo profesional de desarrollo** incluyendo:

- 🧪 **Testing automatizado** con Jest
- 🔍 **Linting y código limpio** con ESLint
- 🔄 **CI/CD integrado** con GitHub Actions
- 📦 **Build optimizado** con Babel
- 🎯 **Control de versiones** con Git

## 🚀 Características Técnicas

### Stack Tecnológico
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Testing**: Jest
- **Linting**: ESLint + ESLint Config
- **Build**: Babel (transpilación y compatibilidad)
- **CI/CD**: GitHub Actions + GitHub Pages

### Prácticas Implementadas
✅ Pruebas unitarias automatizadas  
✅ Validación estática de código  
✅ Transpilación para compatibilidad cross-browser  
✅ Pipeline de integración continua  
✅ Repositorio versionado en GitHub  

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/florensg/ICFlor.git
cd ICFlor

# Instalar dependencias
npm install
```

## 🔧 Scripts Disponibles

```bash
# Ejecutar pruebas
npm test

# Validar código con ESLint
npm run lint:js

# Construir el proyecto
npm run build
```

## 💡 Por Qué Este Proyecto Importa

Este repositorio refleja el **estándar de calidad profesional** en desarrollo web moderno:

- **Automatización**: Pipeline completo que valida cada cambio
- **Escalabilidad**: Estructura lista para crecer
- **Mantenibilidad**: Código limpio y bien documentado
- **Confiabilidad**: Testing garantiza funcionamiento correcto
